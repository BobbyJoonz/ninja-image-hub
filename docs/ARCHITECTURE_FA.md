# معماری ماژولار نسخهٔ ۰٫۵

## اصل جداسازی

`app.py` فقط ورودی ASGI است. `create_app()` در factory به‌ترتیب Runtime، دیتابیس، تنظیمات، سرویس‌ها، چرخهٔ اجرا و مسیرهای HTTP را می‌سازد. وضعیت مشترک به‌صورت صریح در `ctx` به تابع‌ها داده می‌شود. تابع‌های متصل‌شده با `functools.partial` امضای اصلی درخواست را برای FastAPI حفظ می‌کنند. ماژول‌ها هنگام import موتور مرورگر یا زمان‌بند را راه نمی‌اندازند.

این طراحی عمداً پروژه را به میکروسرویس تبدیل نمی‌کند: یک پردازش وب، یک زمان‌بند و یک موتور جدا برای هر حساب داریم. مستقل‌بودن شیء Runtime به معنی مجازبودن چند فرایند روی یک دیتابیس نیست؛ قفل‌ها هنوز در حافظه‌اند.

## صف و حافظه

نسخهٔ قبلی در هر دور تا سقف صف، ردیف‌ها را وارد Python می‌کرد. اکنون SQL با `row_number()` برای هر حساب فقط تا سقف ظرفیت کل، کاندیدا برمی‌گرداند. ایندکس `(status, account_id, created_at, id)` اضافه شده است. کاهش سقف صف به کمتر از backlog نباید حسابی را که کارش دیرتر ثبت شده از فهرست کاندیدا حذف کند؛ برای این رفتار تست منفی داریم.

محدودیت هم‌زمانی کل، محدودیت همان حساب، تعداد تب و cooldown مستقل‌اند. Scheduler کاندیداها را round-robin بررسی می‌کند؛ کارهای queued به تعداد صف به ThreadPool ریخته نمی‌شوند. این تغییر سهمیه یا سرعت واقعی ارائه‌دهنده را افزایش نمی‌دهد.

## فرانت‌اند

Vanilla JavaScript حفظ شده، ولی از ES Module استفاده می‌شود. state وضعیت مشترک، api قرارداد HTTP، controller همگام‌سازی و تغییر صفحه، views نمایش، accounts عملیات حساب و app اتصال رویدادها را انجام می‌دهند. کد خوانا قالب‌بندی شده است و ابزار build اجباری ندارد.

Polling پس از پایان دور قبلی زمان‌بندی می‌شود. Refreshهای هم‌زمان یک Promise مشترک دارند. وقتی تب پنهان است درخواست دوره‌ای نمی‌فرستیم. Analytics و تاریخچهٔ تنظیمات برحسب صفحهٔ فعال خوانده می‌شوند. گالری مسیر صفحه‌بندی جدا دارد؛ اسکرول گالری محدود به ۱۰۰ Job اخیر نیست. پیش‌نمایش تغییرنکرده دوباره در DOM ساخته نمی‌شود. timeout درخواست UI پانزده ثانیه است؛ قطع پاسخ به معنی مجازبودن ثبت دوباره با کلید جدید نیست.

## سازگاری و محدودیت

مسیرهای `/api/*` و `/v1/*` و دانلود اولین تصویر حفظ شده‌اند. مهاجرت‌های SQLite قدیمی در تست بررسی شده‌اند؛ PostgreSQL در این محیط اجرا نشده است. نیاز به Python، Node و موتور مرورگر همچنان برقرار است. تشخیص واقعی Plus، High/Medium/Low رسمی در مرورگر، اتصال آمادهٔ DeepSeek و HA توزیع‌شده اضافه نشده‌اند.

Site صرفاً نمونهٔ ایزوله از همان سورس frontend است؛ `preview/build.py` از آن نسخهٔ قابل انتشار می‌سازد. هیچ آمار نمایشی وارد دیتابیس برنامهٔ واقعی نمی‌شود. هیچ SVG اختصاصی یا تصویر جدیدی طراحی نشده است.
